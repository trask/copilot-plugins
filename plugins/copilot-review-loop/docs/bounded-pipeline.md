# Bounded Pipeline calls

PR Pipeline can add `--bounded-step` to the internal `pipeline` command. Repeat the same target, state path, pipeline run and position, model, policy, and `COPILOT_AGENT_SESSION_ID` until it returns a terminal result. Each call inspects review feedback once or dispatches or observes one hosted decision. `result: waiting` with exit code 0 means work remains pending. It is never review clearance.

The hosted helper prints pending v5 JSON to stdout for direct CLI calls. Under managed execution, the coordinator reads pending JSON from the sealed child `workflow_result`. The helper keeps its checkpoint beside the result path and writes the final result file only after completion; the coordinator requires a matching sealed child result before reading that file. The standalone `agent-task` command and `pipeline` without `--bounded-step` keep their synchronous behavior. If a hosted dispatch cannot be confirmed, the coordinator fails closed instead of sending the request again.

In a standalone run, a follow-up review with new findings starts another iteration in the same invocation state. Only a separate invocation gets a new state file; the run's iteration budget and final clearance check remain bound to its original state.

A later sweep in the same run keeps its spent budget and completed task history, then checks current PR metadata and review feedback. It does not require the prior sweep's branch, draft state, title, or body to match, or require a Description receipt for a metadata edit. The target PR, checkout, policy, model, and run ownership remain bound. An unfinished hosted task cannot be adopted by another sweep.

A tagged `ccr-overview-v2` review that recommends changes supplies review-body feedback even when it has no inline findings. The helper queues that feedback alongside inline and suppressed findings. When it is the sole finding and the verified worker concludes no code change is needed, the stage clears without requesting an unchanged-head review. The clearance is bound to the PR head and exact latest Copilot review; a later head or review requires fresh assessment. A fresh invocation can reuse a completed clearance only while the head, base, review, and overview feedback still match.
